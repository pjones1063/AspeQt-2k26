AspeQt-2k26

Atari Serial Peripheral Emulator / Qt6 Edition

Introduction Requirements Configuration Networking Usage

AspeQt-2k26 is a modernized, cross-platform emulator that bridges your Atari 8-bit computer to modern PC storage and networking via a standard SIO2PC cable.

This edition has been rebuilt on the Qt6 framework to ensure crisp rendering on High-DPI displays and stability on modern operating systems (Windows 11, macOS, Linux).

New in 2k26

  • TNFS Client: Integrated support for mounting images directly from the internet.
  • Y: Clipboard Device: Bi-directional text sharing between PC and Atari.
  • Qt6 Interface: Native drag-and-drop and high-resolution font scaling.

System Requirements

Requires a modern 64-bit operating system. An Atari 8-bit computer and an SIO2PC interface are required for operation.

Hardware Note: We strongly recommend USB adapters based on the FTDI chipset. Prolific or generic chipsets often exhibit timing drift at high speeds (Divisor 0-8).

Configuration

Access the main settings via Tools > Options.

Serial Connection

Windows: Select your COM port (e.g., COM3).
Linux: Select your device node (e.g., /dev/ttyUSB0).

High Speed SIO

  • Divisor 40 (1x): Standard 19200 bps.
  • Divisor 16 (2x): Safe for most cables.
  • Divisor 8 (3x): Recommended for FTDI cables.
  • Divisor 0 (6x): Requires the hisio OS patch on the Atari.

Networking & Integration

TNFS Client

The TNFS client allows you to mount disk images hosted on remote servers (compatible with FujiNet) directly into a drive slot without downloading them first.

  • Setup: Go to Tools > Network and enter the TNFS Server Address.
  • Usage: Open the TNFS Browser, navigate the remote folders, and drag an .atr file to any drive slot.

Y: Clipboard Device

The Y: device acts as a bridge between the host PC's clipboard and the Atari.

  • Read from PC: Copy text on your PC. On the Atari, type COPY "Y:" "E:" to paste it.
  • Write to PC: Print to the Y: device from Atari (e.g., LIST "Y:") to copy text to your PC clipboard.

Usage

Virtual DOS (Folder Images)

You can mount a local PC directory as a writable disk. To boot from a folder, right-click the slot and select Folder Boot Options.

Supported DOS types for booting:

  • Atari DOS 2.5
  • MyDOS 4.5
  • SpartaDOS 3.2G (Limited)

Running Executables

Drag .xex or .com files directly to a slot. AspeQt uses a high-speed internal loader to run these files without requiring a DOS disk.

Printer Emulation

Output sent to P1: is captured by AspeQt. View the output via File > View Printer Output. The viewer automatically handles ATASCII-to-ASCII translation.
