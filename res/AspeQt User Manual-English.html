AspeQt-2k26 User Manual

Introduction | Requirements | Configuration | Networking | Usage

Introduction

AspeQt-2k26 is a cross-platform emulator that lets your Atari 8-bit computer use modern PC storage and networking via a simple SIO2PC cable.

This 2k26 Edition has been modernized with a Qt6 backend for sharp high-DPI rendering and improved stability.

Key Features

  • Qt6 Modernization: Native high-DPI support and stability.
  • TNFS Client: Mount images directly from the internet.
  • Y: Clipboard Device: Bi-directional text sharing between PC and Atari.
  • 15 Disk Drives: Full emulation for D1: through D15:.
  • High Speed SIO: Up to 6x speed (~126kbits/s) with patches.
  • Virtual DOS 2.5: Mount PC folders as writable Atari disks.

System Requirements

Requires Windows 10/11, modern Linux, or macOS. An Atari 8-bit computer and an SIO2PC interface are required.

Hardware Tip: Use adapters based on the FTDI chipset. Other chipsets often fail at high speeds.

Configuration

Access settings via Tools > Options.

Serial Port

  • Windows: Select your COM port (e.g., COM3).
  • Linux: Select your device (e.g., /dev/ttyUSB0).

High Speed SIO

  • Divisor 40 (1x): Standard speed.
  • Divisor 16 (2x): Reliable on most hardware.
  • Divisor 8 (3x): Recommended for FTDI.
  • Divisor 0 (6x): Requires hisio OS patch.

Networking & Integration

TNFS Client

Mount disk images hosted on remote servers (FujiNet compatible) directly into a drive slot.

  • Setup: Go to Tools > Network and enter the TNFS Server Address.
  • Usage: Open the TNFS Browser and drag an .atr file to a drive slot.

Y: Clipboard Device

Bridges your PC's clipboard to the Atari.

  • Read from PC: Copy text on PC. Type COPY "Y:" "E:" on Atari.
  • Write to PC: Print to the Y: device from Atari.

Usage

Folder Images (Virtual DOS)

Mount a PC directory as a disk. Right-click the slot and select Folder Boot Options to make it bootable.

Note: This will copy boot files (dos.sys, dup.sys) into your PC folder, overwriting existing ones.

Running Executables

Drag .xex or .com files directly to a slot. AspeQt uses an internal loader to run these without DOS.

Printer Emulation

The emulator captures output sent to P1:. Open File > View Printer Output to see the text (supports ATASCII translation).
