AspeQt-2k26

Atari Serial Peripheral Emulator for Qt6

Bridging the Gap Between Vintage and Modern.

AspeQt-2k26 transforms your modern PC into a powerful peripheral server for Atari 8-bit computers. Rebuilt entirely on the Modern Qt6 Framework, it ensures long-term stability on Windows 11, macOS, Linux, and Raspberry Pi.

Key Features:

  • High-Speed SIO (Divisor 0 Support)
  • Modem Bridge (RS232 to Telnet Gateway)
  • TNFS Client (FujiNet Protocol)
New in 2k26: Hybrid Devices

This version introduces two powerful new devices for bridging the gap between 8-bit and 64-bit worlds:
  • W: Device (Web Pipe): A multi-channel gateway allowing Atari BASIC to interact with Python scripts, AI models, and Web APIs.
  • Y: Device (Clipboard): Bi-directional copy & paste between the Atari and your PC system clipboard.

Please refer to the User Manual (Help > Documentation) for details.
